# Technical Reference (DOCS.md)

## Makefile Targets

### reports/first_paper.pdf

Builds the first manuscript (Chapter I) as a PDF. Depends on all
Guadalupe Island figure outputs and supplementary maps.

### reports/second_paper.pdf

Builds the second manuscript (Chapter II) as a PDF. Depends on all
combined-island figure outputs and supplementary maps.

### reports/first_paper.md, reports/second_paper.md

Intermediate markdown files generated by concatenating source `.md`
chapters (`1?_*.md` / `2?_*.md`) and processing mustache templates
with `data/processed/methods.json`. These are the pandoc inputs for
PDF generation.

### results_first_paper, results_second_paper, results_clarion

Phony group targets that collect all prerequisite PNGs and CSVs for
each analysis group. Listed in `.PHONY` and used as dependencies
of the PDF targets.

## Pipeline Stages

### 1. Data Preparation

| Target | Function | Input | Output |
|--------|----------|-------|--------|
| `trips_geographic_points_*.csv` | `create_trips` | raw GPS CSV + config JSON | trip-segmented points |
| `trips_summary_*.csv` | `create_trips_summary` | trip points | per-trip summary stats |
| `gps_albatross_all.csv` | `join_gps_data.R` | raw GPS CSVs | combined raw dataset |

### 2. Spatial Computation (create_*)

| Target | Function | Input | Output |
|--------|----------|-------|--------|
| `cache_*.rds` | `create_processed_data` | trip points + config | processed cache (KDE, bootstrap) |
| `ud_polygons_*.gpkg` | `create_individual_kde` | trip points + config | utilization distribution polygons |
| `kba_polygons_*.gpkg` | `create_potential_kba` | cache + config | key biodiversity area polygons |

### 3. Visualization (render_*)

| Target | Function | Input | Output |
|--------|----------|-------|--------|
| `*_individual_kde_*.png` | `render_individual_kde` | UD polygons gpkg | individual KDE figure |
| `*_potential_kba_*.png` | `render_potential_kba` | KBA polygons gpkg | potential KBA figure |
| `*_representative_assessment_*.png` | `render_representative_assessment` | processed cache rds | representative assessment figure |

## Option Flags

All Rscript calls use `get_domain_specific_options()` from the bycatch
package, which parses these command-line flags:

| Flag | Type | Used by |
|------|------|---------|
| `--data-path` | character | `create_*`, some `render_*` |
| `--config-path` | character | `create_*` |
| `--output-path` | character | all |
| `--gpkg-path` | character | `render_individual_kde`, `render_potential_kba` |
| `--rds-path` | character | `render_representative_assessment`, `create_potential_kba` |
| `--percentage-distribution` | integer | `create_individual_kde`, `create_processed_data`, `create_potential_kba` |
| `--smoothing-method` | character | `create_individual_kde`, `create_processed_data`, `create_potential_kba` |
| `--n-iterations` | integer | `create_processed_data` |
| `--population-size` | integer | `create_potential_kba` |
| `--start` / `--end` | character | `create_filtered_gps_between_dates` |
| `--date-column-name` | character | `create_filtered_gps_between_dates` |
