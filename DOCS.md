# Technical Reference (DOCS.md)

## Makefile Targets

### reports/first_paper.pdf

Builds the first manuscript (Chapter I) as a PDF. Depends on combined-island KBA figures, raw points maps, and Mexico reference maps.

### reports/second_paper.pdf

Builds the second manuscript (Chapter II) as a PDF. Depends on combined-island KDE figure outputs, GFW longline hot-spot map, and supplementary maps.

### reports/obsolete_results.pdf

Builds an archive PDF of superseded figures removed from the active manuscripts. Includes individual-colony raw GPS points, Mexico basemaps, and exploratory figures.

### reports/first_paper.md, reports/second_paper.md

Intermediate markdown files generated by concatenating source `.md` chapters (`1?_*.md` / `2?_*.md`) and processing mustache templates with `data/processed/methods.json`. These are the pandoc inputs for PDF generation. The mustache template in `papers/first-paper/first_paper.mustache` is auto-generated and should not be edited directly.

### data/processed/longline_udoi.json

Computed UDOI statistics for the joint albatross-longline overlap index. Contains `udoi`, `n_overlap`, `sum_product`, `cell_area_km2`, `n_total_cells`, and `input`. Script: `src/compute_udoi.R`.

### data/processed/ud_in_grid.gpkg

Continuous N_IND count per KDE grid cell from `track2KBA::findSite(polyOut = FALSE)`. Each cell stores the number of individuals whose core utilization distribution overlaps that cell. Script: `src/export_ud_in_grid.R`.

### data/processed/ud_vms_longline_udoi.gpkg

Joint albatross-longline index: product of sum-normalized N_IND and VMS longline counts per cell, masked to the Pacific Mexico EEZ. Script: `src/export_ud_vms_longline_udoi.R`.

### reports/figures/ud_vms_longline_udoi_map.png

Maps the joint albatross-longline index (UDOI) on KDE grid cells with coastline, EEZ, and MPA context. Title reads the UDOI value dynamically from `data/processed/longline_udoi.json`. Script: `src/plot_ud_vms_longline_udoi.R`.

### reports/figures/gps_albatross_50_percent_potential_kba_ars_all_without_mpa.png

Renders the KBA red polygon contour on coastline and EEZ context. No MPA overlay. Script: `src/plot_potential_kba_all.R`.

### reports/figures/gps_albatross_50_percent_potential_kba_ars_all_with_mpa.png

Renders the KBA red polygon contour with the MPA intersection overlay highlighted. Includes EEZ outline, green MPA fill, and KBA–MPA intersection. Script: `src/plot_kba_mpa_intersection.R`.

### reports/figures/gfw_longline_hotspot_binary_map_all.png

Binary hot-spot classification (z ≥ 1.96) of GFW longline fishing events. Script: `src/plot_gfw_longline_hotspot_binary.R`.

### reports/figures/gfw_longline_hotspot_map_all.png

Continuous hot-spot map of GFW longline fishing events using a viridis inferno palette. Script: `src/plot_gfw_longline_hotspot.R`.

### reports/figures/vms_hotspot_map.png

Getis-Ord Gi* hot-spot map of VMS fishing vessel trajectories. Script: `src/plot_vms_hotspot.R`.

### reports/figures/vms_longline_n_points_map.png

Raw VMS longline point count per KDE grid cell within the Mexican Pacific EEZ. Mapped with coastline, EEZ, and MPA context using the inferno palette. Script: `src/plot_vms_longline_n_points.R`.

### reports/figures/vms_trawler_n_points_map.png

Raw VMS trawler point count per KDE grid cell within the Mexican Pacific EEZ. Mapped with coastline, EEZ, and MPA context using the inferno palette. Script: `src/plot_vms_trawler_n_points.R`.

### reports/figures/combined_fishing_distribution_map.png

UDOI-weighted combined fishing distribution integrating VMS longline and trawler intensities. Each gear is weighted by its individual UDOI before normalizing to a joint probability mass. Script: `src/plot_combined_fishing_distribution.R`.

## Pipeline Stages

### 1. Data Preparation

| Target | Function/Script | Input | Output |
|--------|-----------------|-------|--------|
| `gps_albatross_all.csv` | `src/join_gps_data.R` | raw GPS CSVs | combined raw dataset |
| `longline_events_long.csv` | `src/export_longline_events_long.R` | GFW longline CSV | long-format endpoints |
| `trips_geographic_points_*.csv` | `bycatch::create_trips` | raw GPS CSV + config JSON | trip-segmented points |
| `trips_summary_*.csv` | `bycatch::create_trips_summary` | trip points | per-trip summary stats |

### 2. Spatial Computation (create_*)

| Target | Function/Script | Input | Output |
|--------|----------|-------|--------|
| `individual_kde_*.rds` | `bycatch::create_individual_kde` | trip points + config + trips summary | individual KDE with UD polygons |
| `representative_assessment_*.rds` | `bycatch::create_representative_assessment` | individual KDE RDS | bootstrap representative assessment |
| `kba_polygons_*.gpkg` | `bycatch::create_potential_kba` | assessment RDS + config | key biodiversity area polygons |
| `kba_mpa_intersection_all.gpkg` | `src/export_kba_mpa_intersection.R` | KBA polygons + MPA geopackage | spatially intersected KBA–MPA zones |
| `gfw_longline_in_grid.gpkg` | `src/export_gfw_longline_in_grid.R` | longline endpoints + KDE RDS | longline points per grid cell |
| `gfw_longline_hotspot_all.gpkg` | `src/compute_gfw_longline_hotspot.R` | longline-in-grid gpkg | grid with Getis-Ord Gi* z-scores |
| `ud_in_grid.gpkg` | `src/export_ud_in_grid.R` | representative assessment RDS | N_IND count per KDE grid cell |
| `combined_fishing_distribution.gpkg` | `src/export_combined_fishing_distribution.R` | vms_longline_hotspot + vms_trawler_hotspot + eez_mask + longline_udoi + trawler_udoi | UDOI-weighted combined fishing intensity per cell |
| `ud_vms_longline_udoi.gpkg` | `src/export_ud_vms_longline_udoi.R` | ud_in_grid + vms_longline_hotspot + eez_mask | joint normalized product per cell |
| `udoi.json` | `src/compute_udoi.R` | ud_vms_longline_udoi gpkg | UDOI index and overlap statistics |

### 3. Visualization (render_*)

| Target | Function/Script | Input | Output |
|--------|-----------------|-------|--------|
| `*_individual_kde_*.png` | `bycatch::render_individual_kde` | individual KDE RDS | individual KDE figure |
| `*_potential_kba_*_without_mpa.png` | `src/plot_potential_kba_all.R` | KBA polygons + EEZ | custom KBA contour map |
| `*_potential_kba_*_with_mpa.png` | `src/plot_kba_mpa_intersection.R` | intersection gpkg + KBA + MPA + EEZ | custom KBA–MPA intersection map |
| `*_representative_assessment_*.png` | `bycatch::render_representative_assessment` | assessment RDS | representative assessment figure |
| `gfw_longline_hotspot_map_all.png` | `src/plot_gfw_longline_hotspot.R` | hotspot gpkg + bbox json | continuous hot-spot map |
| `gfw_longline_hotspot_binary_map_all.png` | `src/plot_gfw_longline_hotspot_binary.R` | hotspot gpkg + bbox json | binary hot-spot map |
| `ud_vms_longline_udoi_map.png` | `src/plot_ud_vms_longline_udoi.R` | ud_vms_longline_udoi gpkg + udoi json + eez + mpa | joint albatross-longline index map |
| `vms_longline_n_points_map.png` | `src/plot_vms_longline_n_points.R` | vms_longline_hotspot gpkg + mpa + eez | raw VMS longline point count per grid cell |
| `vms_trawler_n_points_map.png` | `src/plot_vms_trawler_n_points.R` | vms_trawler_hotspot gpkg + mpa + eez | raw VMS trawler point count per grid cell |
| `combined_fishing_distribution_map.png` | `src/plot_combined_fishing_distribution.R` | combined_fishing_distribution gpkg + mpa + eez | UDOI-weighted combined fishing intensity per cell |
