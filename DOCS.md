# Technical Reference (DOCS.md)

## Makefile Targets

### reports/first_paper.pdf

Builds the first manuscript (Chapter I) as a PDF. Depends on all Guadalupe Island figure outputs, supplementary maps, and the KBA/MPA intersection figures.

### reports/second_paper.pdf

Builds the second manuscript (Chapter II) as a PDF. Depends on combined-island figure outputs and supplementary maps.

### reports/first_paper.md, reports/second_paper.md

Intermediate markdown files generated by concatenating source `.md` chapters (`1?_*.md` / `2?_*.md`) and processing mustache templates with `data/processed/methods.json`. These are the pandoc inputs for PDF generation.

### results_first_paper, results_second_paper, results_clarion

Phony group targets that collect all prerequisite PNGs, RDS, and CSV files for each analysis group. Listed in `.PHONY` and used as dependencies of the PDF targets.

### reports/figures/gps_albatross_50_percent_potential_kba_ars_guadalupe_without_mpa.png

Renders the KBA red polygon contour on coastline and EEZ context using the zoom-in bounding box. No MPA overlay. Script: `src/plot_potential_kba_guadalupe.R`.

### reports/figures/gps_albatross_50_percent_potential_kba_ars_guadalupe_with_mpa.png

Renders the KBA red polygon contour with the MPA intersection overlay highlighted. Includes EEZ outline, green MPA fill, and KBA-MPA intersection. Script: `src/plot_kba_mpa_intersection.R`.

## Pipeline Stages

### 1. Data Preparation

| Target | Function/Script | Input | Output |
|--------|-----------------|-------|--------|
| `trips_geographic_points_*.csv` | `bycatch::create_trips` | raw GPS CSV + config JSON | trip-segmented points |
| `trips_summary_*.csv` | `bycatch::create_trips_summary` | trip points | per-trip summary stats |
| `gps_albatross_all.csv` | `src/join_gps_data.R` | raw GPS CSVs | combined raw dataset |

### 2. Spatial Computation (create_*)

| Target | Function | Input | Output |
|--------|----------|-------|--------|
| `individual_kde_*.rds` | `bycatch::create_individual_kde` | trip points + config + trips summary | individual KDE with UD polygons |
| `representative_assessment_*.rds` | `bycatch::create_representative_assessment` | individual KDE RDS | bootstrap representative assessment |
| `kba_polygons_*.gpkg` | `bycatch::create_potential_kba` | assessment RDS + config | key biodiversity area polygons |
| `kba_mpa_intersection_guadalupe.gpkg` | `src/export_kba_mpa_intersection.R` | KBA polygons + MPA geopackage | spatially intersected KBA-MPA zones |

### 3. Visualization (render_*)

| Target | Function/Script | Input | Output |
|--------|-----------------|-------|--------|
| `*_individual_kde_*.png` | `bycatch::render_individual_kde` | individual KDE RDS | individual KDE figure |
| `*_potential_kba_*.png` | `bycatch::render_potential_kba` | KBA polygons gpkg | potential KBA figure from bycatch |
| `*_potential_kba_*_without_mpa.png` | `src/plot_potential_kba_guadalupe.R` | KBA polygons + EEZ + bbox json | custom KBA contour map |
| `*_potential_kba_*_with_mpa.png` | `src/plot_kba_mpa_intersection.R` | intersection gpkg + KBA + MPA + EEZ + bbox json | custom KBA-MPA intersection map |
| `*_representative_assessment_*.png` | `bycatch::render_representative_assessment` | assessment RDS | representative assessment figure |
